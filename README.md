# Data Cleaning & Visualization Project

## Objective
The objective of this project is to clean, process, and analyze a sales dataset and create visualizations to extract meaningful business insights.

## Dataset
Superstore Sales Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning Performed
- Identified missing values
- Filled missing Postal Code values using the mode
- Checked for duplicate records
- Converted date columns to datetime format

## Visualizations Created
- Sales by Category
- Sales by Region
- Top 10 States by Sales
- Sales Distribution
- Top 10 Products by Sales

## Key Findings
-Office Supplies was the highest-selling product category with total sales of 337,978.75, followed by Furniture (243,370.43) and Technology (225,412.19).
-The West region generated the highest sales revenue (269,677.13), while the South region recorded the lowest sales (127,524.88).
-California was the top-performing state with total sales of 169,805.90, significantly higher than any other state in the dataset.
-New York ranked second in sales with 90,610.81, followed by Texas with 70,585.85.
-Sales were concentrated in a few states, with California, New York, and Texas contributing a substantial portion of overall revenue.
-The visualizations revealed noticeable differences in sales performance across categories, regions, and states, highlighting potential areas for business expansion and optimization.

## Conclusion
The dataset was successfully cleaned and analyzed using Python, Pandas, Matplotlib, and Seaborn. Missing values were handled, data quality was verified, and multiple visualizations were created to uncover sales patterns.
The analysis showed that Office Supplies generated the highest sales, the West region was the strongest-performing region, and California was the leading state in terms of revenue. These insights demonstrate how data cleaning and visualization can support data-driven business decision-making.
